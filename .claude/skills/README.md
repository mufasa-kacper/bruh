# Skills

Skills from [slavingia/skills](https://github.com/slavingia/skills) (MIT), based on
*The Minimalist Entrepreneur* by Sahil Lavingia.

Suggested order for finding and launching the app:
`/find-community` → `/validate-idea` → `/processize` → `/mvp` → `/pricing` →
`/first-customers` → `/marketing-plan`. Use `/minimalist-review` to gut-check any decision.
